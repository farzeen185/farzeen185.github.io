| G3P (Global Gravity-based Groundwater Product) |
+------------------------------------------------+

DESCRIPTION:
  This zip-archive contains the most recent version v1.12 of gridded products of the G3P prototype.

  Directory and file structure:
  G3P_v1.12/GWSA/gwsa_g3p_200204_202309_monthly_05_degree_250km_gauss_filtered_gravis.nc        => Groundwater storage anomalies in NetCDF format
  G3P_v1.12/Glacier/glacier_g3p_200204_202309_monthly_05_degree_250km_gauss_filtered_gravis.nc  => Glacier mass-change anomalies in NetCDF format
  G3P_v1.12/RZSM/rzsm_g3p_200204_202309_monthly_05_degree_250km_gauss_filtered_gravis.nc        => Root zone soil moisture anomalies in NetCDF format
  G3P_v1.12/SWE/swe_g3p_200204_202309_monthly_05_degree_250km_gauss_filtered_gravis.nc          => Snow water equivalent anomalies in NetCDF format
  G3P_v1.12/SWS/sws_g3p_200204_202309_monthly_05_degree_250km_gauss_filtered_gravis.nc          => Surface water storage anomalies in NetCDF format
  G3P_v1.12/TWS/tws_g3p_200204_202309_monthly_05_degree_costg_gravis.nc                         => Terrestrial water storage anomalies in NetCDF format

  The G3P gridded products of this data set are visualized at the GravIS portal: http://gravis.gfz.de/gws
  At GravIS, also area-averaged products of this data set are provided for download.

  More information about the G3P project: https://www.g3p.eu/
